# ScreenDrawIyagi (스크린드라이야기) v1.9.0

Windows와 Linux에서 사용할 수 있는 **화면 위 그리기 오버레이 툴**입니다.

화면을 캡처하지 않고, 실행 중인 화면 위에 바로 선·도형·텍스트·이모지를 그릴 수 있습니다.
발표, 강의, 화면 공유, 리뷰 작업에 유용합니다.

---

## ✨ 주요 기능

### 그리기 도구
* **펜** — 자유 곡선 드로잉
* **직선 / 화살표** — 방향 지시선 그리기
* **사각형 / 타원** — 도형 그리기 (채우기 모드 지원)
* **텍스트** — 화면 위에 직접 텍스트 입력 (폰트·크기 설정)
* **이모지 도장** — 이모지 픽커에서 선택 후 클릭 위치에 스탬프
* **지우개** — 일부 영역 지우기
* **형광펜** — 반투명 하이라이트 표시

### 색상 및 스타일
* **색상 선택** — 원하는 색상으로 자유롭게 변경
* **굵기 조절** — 선 굵기 1 ~ 120px
* **채우기 모드** — 사각형·타원 내부 채우기 토글
* **형광펜 모드** — 기존 화면 내용을 반투명으로 강조

### 이모지 픽커
* **9개 카테고리** — 감정 / 손·몸 / 하트 / 동물 / 음식 / 활동 / 여행 / 사물 / 기호
* **도장 모드** — 선택한 이모지를 클릭 위치에 3D 입체 스타일로 스탬프
* **텍스트 삽입** — 텍스트 입력 중 이모지 직접 삽입

### 편의 기능
* **실행 취소(Undo)** — 이전 상태로 되돌리기
* **스냅샷** — 현재 그림 상태를 이미지 파일로 저장
* **전체 지우기** — 캔버스 초기화
* **플로팅 툴바** — 화면 어디서나 드래그해서 위치 조정
* **설정 저장** — 마지막 사용한 색상·굵기·폰트·도구 자동 저장

## 🎮 단축키

| 키 | 기능 |

| `Ctrl + Z` | 실행 취소 |

| `Ctrl + S` | 저장 (투명 PNG) |

| `Ctrl + Q` | 종료 |

| `C` | 캔버스 지우기 |

| `ESC` | 종료 (텍스트 입력이 활성화된 경우 취소) |

| `Ctrl` 키를 누른 상태 | 임시 지우개 (손 떼면 복원) |

| `Shift` 키를 누른 상태 | 임시 직선 (손 떼면 복원) |

| `Ctrl + Enter` | 텍스트 확인 (캔버스에 그리기) |

| 그리기 ✎ | 한 번 클릭 → 캔버스 지우기 + 마우스 모드로 전환 |

|          | 두 번 클릭 → 그리기 유지 + 마우스 모드로 전환 |

GitHub Releases에서 실행 파일을 다운로드합니다.

```bash
chmod +x ScreenDrawIyagi
./ScreenDrawIyagi
```

## 🐧 Linux 설치 참고

Qt6 플랫폼 플러그인이 필요합니다.

```bash
sudo apt install libqt6widgets6 libqt6-xcb-private-plugins
```

이모지 폰트 (미설치 시):

```bash
sudo apt install fonts-noto-color-emoji
```

Wayland 환경에서는 XWayland를 통해 자동 실행됩니다.
