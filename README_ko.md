# ScreenDrawIyagi (스크린드로우이야기) v1.9.0

Windows와 Linux에서 사용할 수 있는 **화면 위 그리기 오버레이 툴**입니다.

색상을 자유롭게 바꾸고, 선 굵기를 조절하고, 도형을 채우고, 형광펜으로 반투명 강조 표시를 하고, 원하는 폰트로 텍스트를 입력하고, 9개 카테고리 이모지 픽커에서 이모지 도장을 찍을 수 있다. 실수는 Undo로 되돌리고, 스냅샷으로 저장하고, 한 번에 전부 지울 수도 있다.

잠시 그리기를 멈추고 Drawing ✎ 도구로 마우스 모드로 바꾸어 바탕화면에 떠있는 앱을 사용 후 다시 그리기 모드로 바꿀수 있다
여기서, 원클릭으로 마우스모드로 바꿀때 그려 놓은 그림은 사라지지만, 더블클릭으로 바꾸고 돌아보면 이전에 그림은 사지지지 않는다.  

플로팅 툴바는 화면 어디에나 드래그해서 놓을 수 있으며, 마지막 설정이 자동 저장되어 언제든 바로 시작할 수 있다.

## ✨ 주요 기능

### 그리기 도구
* **펜** — 자유 곡선 드로잉, 색상·굵기 자유 설정
* **직선 / 화살표** — 직선 및 방향 지시 화살표 그리기
* **사각형 / 타원** — 도형 그리기 (채우기 모드 지원)
* **텍스트** — 화면 위에 직접 텍스트 입력, 폰트·크기 설정
* **이모지 도장** — 9개 카테고리 400여 개 이모지, 클릭 위치에 스탬프
* **지우개** — 특정 영역만 지우기
* **형광펜** — 반투명 오버레이로 화면 내용 강조
* **Drawing ✎** — 마우스 모드로 임시 전환하여 화면 아래 콘텐츠와 상호작용; 단일 클릭은 캔버스 지우기 + 전환, 더블 클릭은 그리기 유지 + 전환

### 색상 및 스타일
* **색상 선택** — 원하는 색상으로 자유롭게 변경
* **굵기 조절** — 선 굵기 1 ~ 120px
* **채우기 모드** — 사각형·타원 내부 채우기 토글
* **형광펜 모드** — 기존 화면 내용을 반투명으로 강조

### 이모지 픽커
* **9개 카테고리** — 감정 / 손·몸 / 하트 / 동물 / 음식 / 활동 / 여행 / 사물 / 기호
* **도장 모드** — 선택한 이모지를 클릭 위치에 3D 입체 스타일로 스탬프
* **텍스트 삽입** — 텍스트 입력 중 이모지 직접 삽입

### 편의 기능
* **실행 취소(Undo)** — 이전 상태로 되돌리기
* **스냅샷** — 현재 그림 상태를 이미지 파일로 저장
* **전체 지우기** — 캔버스 초기화
* **플로팅 툴바** — 화면 어디서나 드래그해서 위치 조정
* **설정 저장** — 마지막 사용한 색상·굵기·폰트·도구 자동 저장

## 🎮 단축키

| 키 | 기능 |
|---|---|
| Ctrl + Z | 실행 취소 |
| Ctrl + S | 저장 (투명 PNG) |
| Ctrl + Q | 종료 |
| C | 전체 지우기 |
| ESC | 종료 (텍스트 입력 중이면 입력 취소) |
| Ctrl 누르는 동안 | 임시 지우개 (놓으면 복원) |
| Shift 누르는 동안 | 임시 직선 (놓으면 복원) |
| Ctrl + Enter | 텍스트 확정 (캔버스에 그리기) |

**Drawing ✎ 도구** — 단일 클릭은 캔버스를 지운 후 전환, 더블 클릭은 그리기를 유지한 채 전환.
